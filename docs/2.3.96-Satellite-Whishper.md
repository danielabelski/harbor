### [Whishper](https://github.com/pluja/whishper)

> Handle: `whishper`<br/>
> URL: [http://localhost:35060](http://localhost:35060)

Whishper is a self-hosted, fully local audio transcription and subtitling suite built on faster-whisper. Upload audio/video files or paste a URL, get timestamped transcripts, edit them in a subtitle editor, download in SRT/VTT/TXT/JSON, and translate them with LibreTranslate.

![Whishper home page with the transcription list and new transcription form](./harbor-whishper.png)

## Starting

```bash
harbor pull whishper
harbor up whishper --open
```

Whishper ships with a MongoDB aux container (`whishper-mongo`) and runs on CPU by default. Whisper models are downloaded from Hugging Face on first use of each model size and cached in the workspace.

To enable translation, start it together with Harbor's [LibreTranslate](./2.3.41-Satellite-libretranslate.md):

```bash
harbor up whishper libretranslate
```

With NVIDIA GPUs (`harbor up whishper nvidia`), the `latest-gpu` image tag is used and the GPU is passed through.

## Usage

- **New transcription**: pick a file (or a YouTube/media URL), choose a model size (`tiny` to `large-v3`) and language, click **Start**. Larger models are slower on CPU but far more accurate.
- **Edit**: opens the subtitle editor with per-segment timing and text.
- **Translate**: requires `libretranslate` to be running; pick a target language and the translation is added to the transcription.
- **Download**: export as SRT, VTT, TXT or JSON.

## Configuration

### Environment Variables

Following options can be set via [`harbor config`](./3.-Harbor-CLI-Reference.md#harbor-config):

```bash
# Host port for the web UI
HARBOR_WHISHPER_HOST_PORT=35060
# Image and tag (compose.x.whishper.nvidia.yml overrides the tag with latest-gpu)
HARBOR_WHISHPER_IMAGE="pluja/whishper"
HARBOR_WHISHPER_VERSION="latest"
# MongoDB aux container
HARBOR_WHISHPER_MONGO_IMAGE="mongo"
HARBOR_WHISHPER_MONGO_VERSION="7"
# Persistent data root (uploads, models, logs, db)
HARBOR_WHISHPER_WORKSPACE="./services/whishper/data"
# Whisper model sizes offered/preloaded by the transcription service (WHISPER_MODELS)
HARBOR_WHISHPER_MODELS="tiny,base,small"
# CPU threads used by faster-whisper
HARBOR_WHISHPER_CPU_THREADS=4
# MongoDB credentials (shared by both containers)
HARBOR_WHISHPER_DB_USER="whishper"
HARBOR_WHISHPER_DB_PASSWORD="whishper"
```

### Volumes

All persistent data lives under `HARBOR_WHISHPER_WORKSPACE`, mounted at `/workspace`. The image hardcodes `/app/uploads` and `/app/models`, so the Harbor entrypoint symlinks those into the workspace. The `whishper-init` sidecar chowns the workspace to your host user (`HARBOR_USER_ID`/`HARBOR_GROUP_ID`) before each start, so files stay manageable without `sudo`. The whishper processes themselves run as root, so freshly written files become host-owned on the next `harbor up`.

- `uploads/` → `/app/uploads` (symlink) — uploaded media files
- `models/` → `/app/models` (symlink) — downloaded faster-whisper models
- `logs/` → `/var/log/whishper` — supervisor logs for the backend, frontend, transcription worker and nginx
- `db/` → `/data/db` in `whishper-mongo` — transcription database (owned by the mongo user)

The container only reports healthy once every model in `HARBOR_WHISHPER_MODELS` has been downloaded; transcriptions submitted before that fail with status `-1`. Watch progress with `docker logs harbor.whishper` and `ls services/whishper/data/models`.

### Integrations

- `compose.x.whishper.libretranslate.yml` — sets `TRANSLATION_ENDPOINT=libretranslate:5000`. Harbor starts the container through `services/whishper/entrypoint.sh`, which rewrites the image's nginx `/languages` upstream to this endpoint (upstream hardcodes `translate:5000` and would otherwise refuse to start without LibreTranslate).
- `compose.x.whishper.nvidia.yml` — switches to the `latest-gpu` image and reserves NVIDIA GPUs.

## Troubleshooting

```bash
harbor logs whishper
harbor exec whishper tail -n 50 /var/log/whishper/transcription.err.log
```

- **Transcription stays "pending"**: first use of a model size downloads it from Hugging Face; watch `transcription.err.log`. On CPU, `medium`/`large` models are slow.
- **Translate button does nothing / language list empty**: `libretranslate` is not running. Start with `harbor up whishper libretranslate`.
- **Poor accuracy**: switch to a larger model (`small.en`, `medium`), or use the GPU image.
