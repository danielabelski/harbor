### [Text Embeddings Inference](https://github.com/huggingface/text-embeddings-inference)

> Handle: `tei`<br/>
> URL: [http://localhost:35030](http://localhost:35030)

Text Embeddings Inference (TEI) is Hugging Face's high-performance server for embedding, reranking and sequence-classification models. In Harbor it is the embeddings backend other services (RAG tools, knowledge bases, bookmark managers) can point at over the network as `http://tei:80`.

## Starting

```bash
harbor pull tei
harbor up tei
```

The default model (`BAAI/bge-small-en-v1.5`) is downloaded on first start into the shared Hugging Face cache and reused afterwards. The container reports healthy once the model is loaded.

Quick check:

```bash
curl http://localhost:35030/embed -H 'Content-Type: application/json' -d '{"inputs":"hello world"}'
curl http://localhost:35030/v1/embeddings -H 'Content-Type: application/json' -d '{"input":"hello world"}'
```

`/v1/embeddings` is OpenAI-compatible, so any client that accepts a custom embeddings base URL can use `http://localhost:35030/v1` (or `http://tei:80/v1` from inside Harbor). Reranker models are served via `/rerank`.

## Configuration

### Environment Variables

Following options can be set via [`harbor config`](./3.-Harbor-CLI-Reference.md#harbor-config):

```bash
# Host port the API is exposed on
HARBOR_TEI_HOST_PORT=35030
# Image and tag; the default tag is the CPU build
HARBOR_TEI_IMAGE="ghcr.io/huggingface/text-embeddings-inference"
HARBOR_TEI_VERSION="cpu-latest"
# Tag used instead when nvidia is part of the selection (harbor up tei nvidia)
HARBOR_TEI_VERSION_CUDA="latest"
# Hugging Face model id (embedding, reranker or classifier)
HARBOR_TEI_MODEL="BAAI/bge-small-en-v1.5"
# Extra CLI flags for text-embeddings-router, e.g. "--max-batch-tokens 32768 --pooling mean"
HARBOR_TEI_EXTRA_ARGS=""
```

Changing the model:

```bash
harbor config set tei.model BAAI/bge-m3
harbor up tei
```

Gated models use `HARBOR_HF_TOKEN`, which is passed into the container as `HF_TOKEN`.

### GPU

Adding `nvidia` to the selection swaps to the CUDA image and reserves all NVIDIA GPUs:

```bash
harbor up tei nvidia
```

Pick a CUDA tag matching your GPU generation (e.g. `turing-latest`, `86-latest`, `89-latest`) via `HARBOR_TEI_VERSION_CUDA` if the default `latest` (Ampere/Hopper) doesn't match. There is no ROCm build of TEI.

### Volumes

- `${HARBOR_HF_CACHE}/hub` (default `~/.cache/huggingface/hub`) is mounted at `/data`, TEI's model cache, so models land in the standard `models--<org>--<name>` layout shared with other Harbor services that use the Hugging Face cache.

## Troubleshooting

```bash
harbor logs tei
```

- Startup takes a while the first time: the model is downloaded and converted. Wait until the log shows `Ready`.
- `Backend does not support a batch size > 8` on CPU is informational; use the CUDA image for larger batches.
- Models without a `pooling` config need `--pooling mean|cls` in `HARBOR_TEI_EXTRA_ARGS`.
