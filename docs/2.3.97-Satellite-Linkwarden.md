### [Linkwarden](https://github.com/linkwarden/linkwarden)

> Handle: `linkwarden`<br/>
> URL: [http://localhost:35070](http://localhost:35070)

Linkwarden is a self-hosted, collaborative bookmark manager. It archives every saved link (screenshot, single-file webpage, PDF, readable view), organises links into collections and tags, offers full-text search via Meilisearch, and can tag links automatically with a local LLM.

![Linkwarden links view with an archived link and AI-generated tags](harbor-linkwarden.png)

## Starting

```bash
harbor pull linkwarden
harbor up linkwarden --open
```

On first launch, open the UI and create an account via **Sign Up** (registration is enabled by default). Linkwarden runs with two auxiliary containers: `linkwarden-db` (PostgreSQL) and `linkwarden-meili` (Meilisearch), started automatically.

### AI tagging

When started together with a Harbor LLM backend, Linkwarden is pre-configured to use it for automatic tagging:

```bash
harbor up linkwarden ollama     # Ollama backend, uses HARBOR_LINKWARDEN_OLLAMA_MODEL
harbor up linkwarden llamacpp   # llama.cpp backend, uses HARBOR_LINKWARDEN_LLAMACPP_MODEL
```

Tagging is off per user until enabled: go to **Settings → Preference → AI Settings** and pick an AI tagging method (e.g. *Auto-generate Tags*). Tags are generated after a link has been archived, so they appear a short while after saving.

Linkwarden picks the OpenAI-compatible provider first when both cross-files are active (i.e. when `llamacpp` and `ollama` are both running).

## Configuration

### Environment Variables

Following options can be set via [`harbor config`](./3.-Harbor-CLI-Reference.md#harbor-config):

```bash
# Host port for the web UI
HARBOR_LINKWARDEN_HOST_PORT=35070
# Image and tag
HARBOR_LINKWARDEN_IMAGE="ghcr.io/linkwarden/linkwarden"
HARBOR_LINKWARDEN_VERSION="latest"
# Root for persistent data (data/, pgdata/, meili/)
HARBOR_LINKWARDEN_WORKSPACE="./services/linkwarden"
# NextAuth session secret - change for anything beyond local use
HARBOR_LINKWARDEN_NEXTAUTH_SECRET="harbor-linkwarden-secret"
# PostgreSQL sidecar
HARBOR_LINKWARDEN_DB_IMAGE="postgres"
HARBOR_LINKWARDEN_DB_VERSION="16-alpine"
HARBOR_LINKWARDEN_DB_PASSWORD="linkwarden"
# Meilisearch sidecar
HARBOR_LINKWARDEN_MEILI_IMAGE="getmeili/meilisearch"
HARBOR_LINKWARDEN_MEILI_VERSION="v1.13.3"
HARBOR_LINKWARDEN_MEILI_MASTER_KEY="harbor-linkwarden-meili"
# Model used for AI tagging with Ollama (harbor up linkwarden ollama)
HARBOR_LINKWARDEN_OLLAMA_MODEL="qwen2.5:1.5b"
# Model used for AI tagging with llama.cpp (harbor up linkwarden llamacpp)
HARBOR_LINKWARDEN_LLAMACPP_MODEL="LiquidAI/LFM2.5-8B-A1B-GGUF:Q8_0"
```

Any other [Linkwarden environment variable](https://docs.linkwarden.app/self-hosting/environment-variables) can be added to `services/linkwarden/override.env`, for example `NEXT_PUBLIC_DISABLE_REGISTRATION=true` after creating your account.

`ALLOW_PRIVATE_NETWORK_ACCESS=true` is set so Linkwarden can archive pages served by other Harbor services on the internal Docker network.

### Volumes

- `services/linkwarden/data` — archived files (screenshots, PDFs, HTML). Linkwarden runs as your host user and the `linkwarden-init` sidecar chowns this directory before each start, so archives stay host-owned.
- `services/linkwarden/pgdata` — PostgreSQL database
- `services/linkwarden/meili` — Meilisearch index

Linkwarden waits for `linkwarden-db` (`pg_isready`) and `linkwarden-meili` (`/health`) to report healthy before running its Prisma migrations, so a cold first start is safe.

## Troubleshooting

```bash
harbor logs linkwarden
```

- **No tags appear** — verify the AI tagging method is enabled in your user preferences and that the LLM backend is running; the worker logs `Auto-tagging link ...` when it picks a link up. Tags are only generated for links with extracted text/description, so pages that fail to archive are not tagged.
- **Archiving stuck** — the bundled headless browser needs a few seconds per link; check the worker output in the logs for `Error` lines.
